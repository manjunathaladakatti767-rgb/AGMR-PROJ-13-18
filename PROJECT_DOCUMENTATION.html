PermGuard Ecosystem

Advanced Browser Security & URL Risk Analysis System

Technical Documentation

1. Executive Summary

PermGuard is a multi-layered security ecosystem designed to provide real-time protection against web-based threats. By combining a browser extension with a sophisticated heuristic scanning engine and a centralized dashboard, the system ensures that every URL visited is analyzed for risks before being logged for administrative review.

2. System Architecture

1. Dashboard (React)

The user-facing portal running on Port 5174. It provides a premium interface for viewing risk analysis reports, monitoring live permissions, and managing security history.

2. Backend API (Node.js/Express)

The central controller running on Port 5000. It manages user authentication (including Google OAuth), database persistence in MongoDB Atlas, and history retrieval.

3. Safety Engine (Risk Scorer)

A specialized service on Port 5001 that evaluates URL integrity. It uses 16+ deterministic rules to calculate risk without external dependency latencies.

4. Chrome Extension

A Manifest V3 browser extension that captures address bar activity and synchronizes it with the AccessShield cloud backend.

3. Security Logic (The 16-Rule Engine)

The system calculates a Risk Score (0-100) by evaluating the following technical red flags:

Rule Category Description Risk Weight
Connection No HTTPS (Unencrypted) +30 Points
Spoofing Homograph / Unicode Attack +50 Points
Spoofing Punycode Masking (xn--) +45 Points
Phishing Suspicious Keywords (Bank, Login, Verify) +25 Points
Path Analysis Dangerous Filenames (Malware, Virus) +40 Points
Technical Raw IP usage instead of Domain +25 Points
Technical Excessive Subdomain Nesting +25 Points
Obfuscation Double Extensions (pdf.exe) +40 Points

Verdict Logic

  • 0 - 39: SAFE - Standard behavior.
  • 40 - 69: SUSPICIOUS - Multiple technical red flags.
  • 70 - 100: DANGEROUS - Confirmed malicious patterns.

4. Operation Workflow

1
Capture: The browser extension detects a URL change in the active tab.
2
Analysis: The extension sends the URL to the Safety Engine for a multi-layered scan.
3
Persistence: The scan result is paired with the user's ID and stored in the MongoDB History collection.
4
Visualization: The result appears in the Dashboard History page with a color-coded status badge.
